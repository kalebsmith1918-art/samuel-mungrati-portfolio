SAMUEL MUNGRATI PORTFOLIO — WEBSITE FILES

1. Extract this ZIP file.
2. Keep index.html and the assets folder together in the same folder.
3. Double-click index.html to preview the website.
4. For GitHub Pages, upload index.html and the assets folder contents so the repository root contains index.html and assets/.

Do not upload only index.html; the local photography images are stored in assets/. YouTube thumbnails require an internet connection.
